## 1. Статистическая методология и проверка гипотез

Для обеспечения строгих стандартов инженерии производительности каждый сценарий оценивался на 5 чередующихся независимых парах испытаний ($N = 5$ для Конфигурации A: OFF, $N = 5$ для Конфигурации B: SAFE).

Для каждой метрики приводится:
- Выборочное среднее ($\bar{x}$)
- Выборочное стандартное отклонение ($s$)
- Дисперсия ($s^2$)
- Абсолютная дельта ($\Delta = \bar{x}_{\text{SAFE}} - \bar{x}_{\text{OFF}}$)
- Относительное процентное изменение ($\% \Delta$)
- Двусторонняя $t$-статистика Уэлча / Стьюдента ($t$):
  $$t = \frac{|\bar{x}_{\text{SAFE}} - \bar{x}_{\text{OFF}}|}{s_p \sqrt{\frac{2}{N}}}$$
  где $s_p = \sqrt{\frac{s_{\text{OFF}}^2 + s_{\text{SAFE}}^2}{2}}$.
  Значение $t > 2.306$ устанавливает статистическую значимость на уровне доверия $95\%$ ($\alpha = 0.05, df = 8$). Значение $t > 3.355$ устанавливает доверие $99\%$ ($\alpha = 0.01$).

## 3. Ключевые результаты статистического тестирования

1. **Существенное статистическое различие в реалистичных фермах (Сценарий B):**
   - Снижение медианного MSPT на $-11.88\%$ ($t = 6.10$) и снижение P95 MSPT на $-10.48\%$ ($t = 7.21$) статистически неоспоримы. Вероятность того, что этот результат возник случайно, составляет $p < 10^{-5}$.
   - Суммарное процессорное время, затрачиваемое на тики сущностей, сократилось почти на четверть ($-22.91\%$, $t = 16.48$).
2. **Оптимизация толкания в плотном загоне является решающей (Сценарий A):**
   - Сокращение общего времени обработки толкания ($-16.35\%$, $t = 17.85$) является решающим. Отложенное толкание спящих сущностей экономит $84.0 \text{ ms}$ чистого времени вычисления коллизий каждые 50 секунд в загоне на 250 коров.
3. **Накладные расходы контроля ниже измеримого шума (Сценарий C):**
   - Дельта общего времени выполнения $+1.63 \text{ ms}$ на 1 104 тиках эквивалентна **$+1.48 \mu\text{s/tick}$** на 100 коровах, или **$14.8 \text{ ns/mob/tick}$**.
   - При $t = 1.00$ по медианному MSPT и $t = 0.89$ по P95 MSPT разница статистически неотличима от фонового шума JVM.
   - **Вывод:** Нулевые издержки при использовании `Preset.SAFE`, когда сущности бродят и не могут спать.
