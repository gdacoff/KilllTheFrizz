## 2. Результаты проверки гипотез

1. **Гипотеза $H_1$ (сокращение числа вызовов): ПОДТВЕРЖДЕНА.**
   - Прогноз: $\approx 75\%$.
   - Измерено по сценариям: **72.4% – 74.7%**.
   - Оставшиеся 25% представляют собой точное выполнение по модулю 4 для неподвижных жителей плюс короткие переходы в состояние бодрствования.
2. **Гипотеза $H_2$ (сокращение времени обработки Brain): ПОДТВЕРЖДЕНА.**
   - Прогноз: $\approx 25\%$.
   - Измерено по сценариям: **19.1% – 27.5%**.
   - Объясняет, почему сокращение числа вызовов не равно сокращению времени: активные тики обрабатывают поставленные в очередь сенсорные обновления и рабочие взаимодействия.
3. **Гипотеза $H_3$ (сокращение MSPT в сценариях с жителями): ПОДТВЕРЖДЕНА.**
   - Сценарий 1 (Stall): **-29.7% MSPT** ($p = 0.012 < 0.05$).
   - Сценарий 3 (Active): **-32.9% MSPT** ($p = 0.041 < 0.05$).
   - Сценарий 5 (Village Workload): **-19.4% Median MSPT, -27.7% P95 MSPT** ($p = 0.023 < 0.05$).
4. **Гипотеза $H_4$ (нейтральность контроля): ПОДТВЕРЖДЕНА.**
   - Разница MSPT в контроле ($+0.07$ ms) статистически неотличима от нуля ($p = 0.68 > 0.05$).
   - P95 MSPT снизился на $-1.1\%$. В системы, не связанные с жителями, не вносится никаких накладных расходов.

## 3. Оставшаяся аномалия Mixed 200

В сценарии 2 (Mixed 200), несмотря на снижение числа вызовов Brain на **-72.4%** и снижение Brain CPU time на **-19.1%**, общий MSPT остался на уровне около 5.1–5.5 ms.

Детальная разбивка KtfProfiler изолирует первопричину:
- `serverAiStep`: 28 ms
- `Brain.tick`: 271 ms
- `pushEntities`: **свыше 450 ms** на 160 животных в загоне!

Обработка столкновений животных (`pushEntities` и пространственные запросы кандидатов по AABB) подавляюще доминирует в общей длительности тика в плотных смешанных загонах. Это эмпирическое наблюдение непосредственно переходит в **Фазу 7.10**.
